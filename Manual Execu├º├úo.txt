=== EllencoCheck - Manual de Execucao (MySQL / XAMPP) ===

1) Ligue o XAMPP e inicie o modulo MySQL no painel de controle
   (o Apache do XAMPP nao precisa estar ligado).

2) No terminal:

   cd backend
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python app.py

3) Abra no navegador:

   http://localhost:5000

O banco de dados "ellencocheck" e todas as tabelas sao criados
automaticamente na primeira execucao, usando os dados padrao do
XAMPP (usuario "root", sem senha, porta 3306). Se o seu MySQL usa
outra configuracao, defina as variaveis de ambiente MYSQL_HOST,
MYSQL_PORT, MYSQL_USER, MYSQL_PASSWORD e MYSQL_DATABASE antes do
passo 2.

Alternativa: o arquivo backend/schema.sql tambem pode ser importado
direto pelo phpMyAdmin (http://localhost/phpmyadmin), aba SQL.

---Docker---
CMD

docker build -t ellencocheck .

docker run -p 5000:5000 -e MYSQL_HOST=host.docker.internal ellencocheck
